Besart's Logbook

Week 13

Tasks Completed

System and Database Setup

This week I continued working on the integration of the elevator website and database. I configured my local development environment, imported the elevator database, and verified that the PHP website could communicate with the MySQL database.

This also gave me a better understanding of how the website, database, supervisory controller, and CAN network will work together during the final system integration.

Interactive Elevator Slider

I began developing a unique GUI feature that allows the user to select an elevator destination using a vertical slider instead of traditional floor buttons. The slider contains positions for floors one, two, and three and displays the currently selected floor.

A new page was created for the slider along with separate CSS and JavaScript files. The interface was designed to visually represent the three elevator floors while displaying the current floor, selected floor, and current operating mode.

Database Integration

The slider was connected to the existing floor request backend. When the user selects a floor and sends the request, JavaScript submits the selected floor to the PHP endpoint using JSON.

The PHP backend validates the request and records it in the can_transaction table, allowing the new interface to use the same database and CAN request structure as the existing elevator controls.

Slider Interaction and Layout

I also worked on improving the usability and appearance of the slider. The interface was redesigned into a compact layout with floor labels, a vertical slider, elevator status information, and the floor request control grouped together.

I also worked on adding mouse-wheel control so the user can move between floors by scrolling up or down while interacting with the slider.

Challenges

One challenge was recreating the project database and server configuration in my local development environment. Another challenge was integrating the new slider without changing the existing floor request backend or interfering with the original elevator controls.

What I Learned

This week improved my understanding of frontend and backend integration. I gained more experience using CSS and JavaScript to send JSON requests to PHP and using PHP to validate and store those requests in a MySQL database.

I also gained experience designing an interactive GUI component while reusing an existing backend interface rather than creating a separate database implementation.
